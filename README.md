## 🧠 How I work with AI

1. **Plan** — spec, data model and acceptance criteria first.
2. **Generate** — AI agents write a large part of the first draft.
3. **Review** — I correct it by hand against the requirements.
4. **Prove** — tests lock the behaviour; CI runs lint, tests and build.
